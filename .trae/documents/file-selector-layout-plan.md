# 日志文件选择器布局调整计划

## 需求分析

1. **布局调整**：将"日志文件+输入框+浏览按钮"从顶端标题栏移到时间栏上面，作为独立的一行
2. **完善浏览功能**：确保浏览按钮能正确弹出文件选择器
3. **新增打开按钮**：在浏览按钮左边添加"打开"按钮，用于加载输入框中的文件路径

## 当前布局结构

```
TitleBar (标题栏 + 文件选择器)  ← 需要拆分
ControlBar (时间筛选 + 搜索框)
CategoryTabs (分类标签)
MainContent (主内容区)
StatusBar (状态栏)
```

## 目标布局结构

```
TitleBar (仅标题栏)
FileBar (日志文件选择器)  ← 新增独立行
ControlBar (时间筛选 + 搜索框)
CategoryTabs (分类标签)
MainContent (主内容区)
StatusBar (状态栏)
```

## 实现步骤

### 步骤 1：创建 FileBar 组件
- 创建 `src/lib/components/FileBar.svelte`
- 包含元素：
  - "日志文件" 标签
  - 文件路径输入框（支持手动输入、粘贴路径）
  - "打开" 按钮（加载输入框中的路径）
  - "浏览" 按钮（弹出文件选择器）
- 功能：
  - 输入框支持 Enter 键加载文件
  - 显示当前加载的文件路径
  - 加载中状态显示

### 步骤 2：简化 TitleBar 组件
- 移除文件选择器相关代码
- 恢复为简洁的标题栏（仅显示应用名称和版本）

### 步骤 3：更新主页面布局
- 在 `+page.svelte` 中引入 FileBar 组件
- 调整布局顺序：TitleBar → FileBar → ControlBar → ...
- 添加 CSS 变量 `--filebar-height`

### 步骤 4：完善文件选择器功能
- 确保 `@tauri-apps/plugin-dialog` 的 `open` API 正确调用
- 处理文件选择后的路径回填和文件加载

## 文件修改清单

| 文件 | 操作 |
|------|------|
| `src/lib/components/FileBar.svelte` | 新建 |
| `src/lib/components/TitleBar.svelte` | 简化 |

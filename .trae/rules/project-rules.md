# Project Rules (Core)

## 1. 架构约束
- 必须先设计架构，再写代码
- 所有模块必须单一职责
- 禁止跨层调用
- 禁止超大函数（>80行）

## 2. 结构约束
- 必须保持清晰分层：
  Interface / Application / Domain / Infrastructure
- 禁止随意新增目录
- utils 不得包含业务逻辑

## 3. 开发流程
必须遵循：
1. 需求理解
2. 任务拆解
3. 架构设计
4. 编码
5. 测试

禁止跳过设计直接编码

## 4. 编码规范
- 必须处理异常
- 禁止重复代码
- 禁止魔法值
- 必须语义化命名

## 5. 依赖控制
- 优先标准库
- 禁止随意新增依赖
- 新依赖必须说明用途

## 6. AI行为约束
- 优先输出结构，而不是代码
- 不得猜测需求
- 不得过度设计

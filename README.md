# LogViewer - 高性能日志查看器

**LogViewer** 是一款专为处理大型日志文件设计的跨平台桌面应用，采用 **Rust + Svelte** 技术栈构建。通过内存映射文件技术实现 GB 级日志文件的秒级加载，配合智能模板系统自动识别多种日志格式，提供流畅的千万级日志条目浏览体验。

**核心亮点**：
- 🚀 **极致性能**：内存映射技术 + 位图索引，1GB 文件加载仅需 15-20 秒
- 🧩 **智能解析**：内置 Linux Syslog、Nginx Access Log 等模板，支持自定义正则表达式
- 🔍 **高效搜索**：模糊/精确/正则三种模式，毫秒级响应
- 📊 **灵活过滤**：级别、时间、字段多维度筛选，支持 Extra 字段索引查询

## 项目简介

在日常开发和运维工作中，日志文件往往非常庞大，传统的文本编辑器难以高效处理。LogViewer 应运而生，旨在解决以下痛点：

- **大文件加载慢**：使用内存映射技术，实现 GB 级文件的秒级加载
- **日志格式多样**：内置多种日志格式模板，支持自定义正则表达式解析任意格式
- **检索效率低**：基于位图索引的高效过滤引擎，毫秒级响应
- **信息提取困难**：自动提取时间戳、级别、来源等关键字段，支持额外字段扩展

## 功能特性

### 核心功能

- **大文件支持**：使用内存映射文件（mmap）技术，支持 GB 级日志文件
- **智能解析**：自动识别日志格式，提取级别、时间戳、来源等信息
- **级别分类**：自动识别日志级别（FATAL/ERROR/WARN/INFO/DEBUG/TRACE），支持快速过滤
- **虚拟滚动**：支持千万级日志条目的流畅滚动和快速跳转
- **多格式查看**：支持文本、HTML、JSON、XML 四种查看模式

### 搜索与过滤

- **搜索模式**：模糊搜索、精确匹配、正则表达式
- **搜索范围**：全部范围、来源、内容、自定义字段
- **时间筛选**：按时间范围快速筛选日志
- **级别过滤**：按日志级别快速过滤

### 编码支持

- **编码支持**：自动检测、UTF-8、ANSI、UTF-16 LE/BE

### 模板系统

- **内置模板**：预置 Linux Syslog、Linux Auth Log、Nginx Access Log 等常用格式
- **自定义模板**：支持创建、编辑、删除自定义正则表达式模板
- **模板自动检测**：打开文件时自动识别最佳匹配模板（匹配率 > 50%）
- **实时测试**：编辑模板时可粘贴日志行实时测试匹配效果
- **AI 辅助生成**：提供提示词模板，可借助 AI 快速生成正则表达式
- **导入导出**：支持模板的 JSON 格式导入导出，便于分享和备份
- **Extra 字段**：自动提取额外字段并支持过滤查询

### 其他特性

- **主题切换**：支持深色/浅色主题
- **拖拽加载**：支持拖拽文件到窗口直接打开
- **文件关联**：可关联 .log 等文件类型
- **多实例运行**：支持同时运行多个程序实例，每个实例独立处理不同文件
- **日志导出**：支持导出过滤后的日志和搜索结果（纯文本/JSON 格式）

## 模板系统详解

### 模板语法

模板使用 **Rust 正则表达式** 的命名捕获组语法：

```regex
(?P<字段名>正则表达式)
```

### 核心字段名

| 字段名 | 支持的别名 | 用途 |
|--------|-----------|------|
| `timestamp` | `time`, `ts` | 日志时间戳 |
| `level` | `lvl`, `severity` | 日志级别 |
| `source` | `logger`, `src` | 日志来源 |
| `message` | `msg`, `content`, `summary` | 日志消息内容 |

其他字段名会自动作为 **Extra 字段** 存储，支持后续过滤查询。

### 内置模板

| 模板名称 | 适用场景 | 提取字段 |
|---------|---------|---------|
| **Linux Syslog** | Linux 系统日志 | timestamp, hostname, source, message |
| **Linux Auth Log** | Linux 认证日志 | timestamp, hostname, source, message |
| **Nginx Access Log** | Nginx 访问日志 | ip, user, timestamp, request, status, size, referer, user_agent |

### 自定义模板示例

**Java Log4j 格式**：
```regex
^(?P<timestamp>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2},\d{3})\s+(?P<level>\w+)\s+\[(?P<source>[^\]]+)\]\s+(?P<message>.+)$
```

**匹配示例**：
```
2024-01-15 10:30:45,123 INFO  [com.example.Service] User login success
```

**提取结果**：
- `timestamp`: 2024-01-15 10:30:45,123
- `level`: INFO
- `source`: com.example.Service
- `message`: User login success

### 模板自动检测

打开日志文件时，系统会：
1. 读取文件前 100 行
2. 遍历所有模板计算匹配率
3. 选择匹配率 > 50% 且最高的模板
4. 自动应用该模板解析整个文件

### 创建自定义模板

1. 点击工具栏的「模板管理」按钮
2. 点击「新建模板」
3. 输入模板名称和正则表达式
4. 在测试区域粘贴示例日志行验证匹配效果
5. 设置优先级（数值越大优先级越高）
6. 保存后即可使用

### AI 辅助生成

模板编辑器提供 AI 辅助功能，点击「AI 辅助」按钮可复制提示词模板，粘贴到 AI 对话框中并附上日志示例，即可快速生成正则表达式。

## 支持的日志格式

应用内置模板自动识别以下常见日志格式：

| 格式类型 | 示例 |
|---------|------|
| **Linux Syslog** | `2024-01-15T10:30:45.123456+08:00 hostname service: message` |
| **Linux Auth Log** | `2024-01-15T10:30:45.123456+08:00 hostname sshd[1234]: message` |
| **Nginx Access** | `192.168.1.1 - - [15/Jan/2024:10:30:45 +0800] "GET /api HTTP/1.1" 200 1234` |

对于其他格式，可通过自定义模板解析：

| 格式类型 | 示例 |
|---------|------|
| **标准格式** | `2024-01-15 10:30:45.123 INFO  [module] message` |
| **Log4j格式** | `2024-01-15 10:30:45,123 INFO  [module] message` |
| **ISO格式** | `2024-01-15T10:30:45.123Z INFO module - message` |
| **紧凑格式** | `2024-01-15 10:30:45 INFO module: message` |

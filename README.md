# LargeLogViewer - 高性能多模板大日志查看器

一款专为处理大型日志文件设计的跨平台桌面应用，采用 **Tauri + Rust + Svelte + Seld** 技术栈构建。通过内存映射文件技术实现 GB 级日志文件的秒级加载，配合智能模板系统自动识别多种日志格式，提供流畅的千万级日志条目浏览体验。

## 功能特性

### 核心特点

| 特性           | 说明                                 |
| ------------ | ---------------------------------- |
| 🚀 **高性能**   | Rust 后端 + 内存映射文件，1GB 文件加载约 15-20 秒 |
| 🧩 **智能解析**  | 模板系统支持 3 种内置格式 + 无限自定义格式           |
| 🔍 **极速检索**  | RoaringBitmap 位图索引，筛选响应 < 100ms    |
| 📊 **海量数据**  | 虚拟滚动支持千万级日志条目流畅浏览                  |
| 🎨 **现代 UI** | Svelte 5 前端，支持深色/浅色主题              |
| 💾 **低内存**   | 内存占用 < 文件大小的 1 倍                   |

### 搜索与过滤

- **搜索模式**：模糊搜索、精确匹配、正则表达式
- **时间筛选**：按时间范围快速筛选日志
- **级别过滤**：按日志级别快速过滤
- **高级筛选**：支持模板提取的extra额外字段过滤

### 编码支持

- **编码支持**：自动检测、UTF-8、ANSI、UTF-16 LE/BE

### 模板系统

- **内置模板**：预置 Linux Syslog、Linux Auth Log、Nginx Access Log 等常用格式
- **自定义模板**：支持创建、编辑、删除自定义正则表达式模板
- **模板自动检测**：打开文件时自动识别最佳匹配模板（匹配率 > 50%）
- **实时测试**：编辑模板时可粘贴日志行实时测试匹配效果
- **AI 辅助生成**：提供提示词模板，可借助 AI 快速生成正则表达式
- **导入导出**：支持模板的 JSON 格式导入导出，便于分享和备份

### 其他特性

- **主题切换**：支持深色/浅色主题
- **拖拽加载**：支持拖拽文件到窗口直接打开
- **多实例运行**：支持同时运行多个程序实例，每个实例独立处理不同文件
- **筛选导出**：支持导出过滤后的日志和搜索结果（纯文本/JSON 格式）

## 安装使用

### 从发布包安装

下载最新的 `.exe` 安装包，双击安装即可。

### 从源码构建

```bash
# 克隆仓库
git clone https://github.com/your-repo/large-log-viewer.git
cd large-log-viewer

# 安装依赖
pnpm install

# 开发模式运行
pnpm tauri dev

# 构建发布版本
pnpm tauri build
```

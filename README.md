# LogViewer - 高性能日志查看器

一款专为处理大型日志文件设计的桌面应用，支持几百MB至几GB的日志文件快速加载、分类、搜索和查看。

## 功能特性

### 核心功能

- **大文件支持**：使用内存映射文件（mmap）技术，支持 GB 级日志文件
- **智能解析**：自动识别日志格式，提取级别、时间戳、来源等信息
- **级别分类**：自动识别日志级别（FATAL/ERROR/WARN/INFO/DEBUG/TRACE），支持快速过滤
- **虚拟滚动**：支持千万级日志条目的流畅滚动和快速跳转
- **多格式查看**：支持文本、HTML、JSON、XML 四种查看模式

### 搜索与过滤

- **搜索模式**：模糊搜索、精确匹配、正则表达式
- **搜索范围**：全部范围、来源、内容、自定义字段
- **时间筛选**：按时间范围快速筛选日志
- **级别过滤**：按日志级别快速过滤

### 编码与模板

- **编码支持**：自动检测、UTF-8、ANSI、UTF-16 LE/BE
- **模板系统**：
  - 内置多种常用日志格式模板
  - 支持自定义正则表达式模板
  - 模板自动检测功能

### 其他特性

- **主题切换**：支持深色/浅色主题
- **拖拽加载**：支持拖拽文件到窗口直接打开
- **文件关联**：可关联 .log 等文件类型

## 技术栈

### 后端 (Rust)

- **桌面框架**: Tauri 2.x
- **数据库**: sled 嵌入式数据库
- **文件读取**: memmap2 内存映射
- **索引引擎**: RoaringBitmap 位图索引
- **并行处理**: rayon + tokio
- **日志解析**: regex 多模式匹配

### 前端 (TypeScript)

- **框架**: Svelte 5 + SvelteKit
- **语言**: TypeScript
- **构建工具**: Vite
- **状态管理**: Svelte Stores

## 搜索功能

### 搜索模式

| 模式 | 说明 |
|------|------|
| **模糊** | 不区分大小写的包含匹配，适合快速查找 |
| **精确** | 区分大小写的精确匹配，适合精确查找 |
| **正则** | 支持标准正则表达式语法，适合复杂模式匹配 |

### 搜索范围

| 范围 | 说明 |
|------|------|
| **全部范围** | 搜索日志原始内容及所有解析字段 |
| **来源** | 仅搜索来源（Source）字段 |
| **内容** | 仅搜索日志消息内容 |
| **自定义字段** | 根据模板定义的额外字段 |

## 支持的日志格式

应用自动识别以下常见日志格式：

1. **标准格式**: `2024-01-15 10:30:45.123 INFO  [module] message`
2. **Log4j格式**: `2024-01-15 10:30:45,123 INFO  [module] message`
3. **ISO格式**: `2024-01-15T10:30:45.123Z INFO module - message`
4. **紧凑格式**: `2024-01-15 10:30:45 INFO module: message`

也支持通过自定义模板解析其他格式。
